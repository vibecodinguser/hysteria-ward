# Метки триажа

Скиллы оперируют пятью каноническими ролями триажа. Этот файл сопоставляет роли со строками меток, реально используемыми в трекере этого репозитория.

| Метка в mattpocock/skills | Метка в нашем трекере | Значение                                  |
| ------------------------- | --------------------- | ----------------------------------------- |
| `needs-triage`            | `needs-triage`        | Сопровождающий должен оценить задачу      |
| `needs-info`              | `needs-info`          | Ждём от автора дополнительной информации  |
| `ready-for-agent`         | `ready-for-agent`     | Полностью описана, готова для AFK-агента  |
| `ready-for-human`         | `ready-for-human`     | Требует реализации человеком              |
| `wontfix`                 | `wontfix`             | Обрабатывать не будем                     |

Когда скилл упоминает роль (например, «применить метку готовности для AFK-агента»), используй соответствующую строку метки из этой таблицы.

Редактируй колонку «Метка в нашем трекере», если поменяешь словарь на своём трекере.
