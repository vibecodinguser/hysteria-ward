# Поддерживаются только aarch64 и x86_64

**Статус:** принято

Гарантируем и тестируем **`aarch64`** (Keenetic Ultra KN-1811 — референс приёмки) и **`x86_64`** (VPS). Остальные
значения `GOARCH` собираются в CI «на сборку», но не тестируются и не обещаются. **MIPS/MIPSEL — вне области
поддержки**, хотя ТЗ 1.2 его перечисляет.

Причина: MIPS-модели Keenetic (например Carrier KN-1721, MT7628N) не имеют официально поддержанного Entware — то
есть настоящей цели для MIPS-сборки нет.

**Последствия.** Возврат MIPS остаётся дешёвым, пока держится дисциплина: только pure-Go зависимости; счётчики
трафика и любые размеры — `uint64`, без приведения к `int`; 64-битные атомики только через `atomic.Uint64` /
`atomic.Int64` (на 32-битных MIPS сырые функции требуют 8-байтового выравнивания); зависимости обязаны
поддерживать 32-битные платформы. При соблюдении всего этого возврат MIPS — примерно день работы (строка в матрице
CI и прогон под qemu); при нарушении — недели вычистки.
