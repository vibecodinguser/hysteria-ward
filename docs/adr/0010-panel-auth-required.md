# Авторизация панели обязательна

**Статус:** принято (заменяет ADR-0004)

Панель **всегда требует входа**. Режима «пароль не задан, интерфейс открыт» не существует. Пароль задаётся при
установке скриптом и обязателен: либо вводится интерактивно, либо генерируется и печатается один раз.

Хранится Argon2id-хеш. Сессия — HTTP-only cookie, TTL 15 минут с продлением по активности, без привязки к IP
(мобильные сети меняют адрес). Запросы, изменяющие состояние, требуют CSRF-токен. После пяти неудачных попыток
подряд задержка ответа нарастает.

Причины: (1) ADR-0004 принимался для домашнего роутера, куда снаружи не попасть иначе как через сам роутер;
(2) панель на VPS стоит на публичном адресе с доменом и сертификатом — это ровно та поверхность, которую сканируют
и перебирают; (3) установочный скрипт и так интерактивен, поэтому задать пароль в момент установки ничего не
стоит, и отдельный режим «сначала без пароля, потом включу» только создаёт окно, когда панель открыта.

**Учётные данные по умолчанию.** На чистой базе панель заводит себе `admin`/`admin` и предупреждает об этом в
журнале. Так `serve` работоспособен сам по себе: без учётных данных войти было бы негде, а настраивать их с
командной строки вслепую — хуже, чем войти и сменить пароль в интерфейсе. Настоящий пароль задаёт `install.sh`
командой `hysteria-ward passwd`. Пока действует пароль по умолчанию, панель наружу не выставляется: по умолчанию
она слушает `127.0.0.1`, а публичный доступ — отдельное действие, которое панель отклоняет, пока пароль не
сменён (ADR-0013).

**Последствия.** Пункт 4.3 ТЗ в части «форма входа по мастер-паролю» отменяется. Появляется обязанность `install.sh`
спросить или сгенерировать пароль и не завершаться без него. Восстановление забытого пароля — только через доступ
к файловой системе сервера, сброса по почте не будет.

**Рассмотренные варианты.** Сохранить «пароль по умолчанию выключен», но включать его автоматически при первом
выходе в публичный режим — отклонён: два режима поведения одного и того же эндпоинта дают вдвое больше путей
ошибки, а выигрыш только в удобстве локальной отладки, которая решается флагом `--debug`.
