# Доставка через GitHub Releases, без самообновления

**Статус:** принято

ТЗ 5.2 ссылается на вымышленный `repo.your-domain.zone` и предлагает установку через `curl ... | sh`. Решение:
готовые бинарники — в **GitHub Releases**, установка и обновление — через `install.sh`. **Самообновление демона не
делаем.** Пакет `.ipk` и opkg-репозиторий — отдельный этап.

Причины: (1) нужен реальный хостинг вместо несуществующего домена; (2) самоподмена бинарника на устройстве с
небольшим flash и без физического доступа — самый быстрый способ получить неработающий роутер.

**Последствия.** Обновление всегда является явным действием администратора; автообновления и «тихих» апгрейдов нет.
