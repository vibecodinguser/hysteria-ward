# Пароль веб-интерфейса по умолчанию выключен

**Статус:** принято (осознанное отступление от ТЗ 4.3)

ТЗ 4.3 требует формы входа по мастер-паролю администратора. Владелец проекта счёл пароль избыточным, поскольку
сеть считается локальной, и попросил включать его вручную. Решение: **пароль по умолчанию не задан, включается
вручную в настройках**.

**Принятый риск** (зафиксирован осознанно, а не по недосмотру): любой, кто дотянется до порта 2222 в LAN —
включая заражённое IoT-устройство или гостя, — получает полный доступ к управлению туннелями и может скачать
пароли всех клиентов, так как те хранятся обратимо (см. ADR-0006). Риск не ограничен LAN: интерфейс может
оказаться доступен извне через KeenDNS или проброс порта, при том что адрес бинда при этом не меняется. Для
опенсорсного проекта это дефолт, который разойдётся по чужим роутерам.

**Митигация** (согласована): задержка после 5 неудачных попыток входа, TTL сессии 15 минут, интерфейс работает
только по HTTPS, сессии не привязываются к IP.
