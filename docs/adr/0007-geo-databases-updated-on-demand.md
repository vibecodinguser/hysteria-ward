# Геобазы ACL обновляются только явным действием

**Статус:** принято

Сервер Hysteria 2 поддерживает правила `geosite:<name>` и `geoip:<cc>`, но базы данных в бинарник не встроены:
если указать только правила, ядро само скачивает `geoip.dat` (~16.6 МБ) и `geosite.dat` (~11.2 МБ) с внешнего CDN
при старте.

Решение: в менеджере геобазы обновляются **по явной команде в интерфейсе** (и можно указать собственные файлы).
Молчаливого скачивания при старте нет.

Причина: поход в интернет и почти 28 МБ на устройстве не должны происходить без ведома владельца роутера;
поведение должно быть предсказуемым и воспроизводимым.

**Последствия.** Для правил на основе геобаз требуется предварительное обновление; правила по адресам и доменам
работают всегда.
