# Самообновление панели

**Статус:** принято (заменяет ADR-0008 в части отказа от самообновления)

Панель обновляется скриптом `update.sh`, который скачивает релизный артефакт из GitHub Releases, подменяет бинарь и
применяет миграции схемы. Скрипт **версионирует применённое** и повторный запуск безопасен: уже применённые
миграции пропускаются. Поддерживаются `--dry-run` (показать, ничего не менять), `--status` (диагностика без прав),
`--repair` (перегенерировать конфиг из хранилища), `--force` (перепрогнать). Перед подменой — бэкап данных.

Причины: (1) требование владельца, выросшее из практики эталонных решений; (2) без обновления на руках у людей
остаются версии с известными дефектами, потому что заходить на сервер по SSH ради каждого патча никто не станет;
(3) самообновление *данных* уже есть по ADR-0002 (миграции + автобэкап), и отказ от самообновления *кода* рядом с
ним непоследователен.

**Последствия.** Появляется требование к релизному процессу: артефакт должен быть воспроизводим, а версия —
проверяема. Нужен способ отката: сохраняем предыдущий бинарь до успешного старта нового. Если новый процесс не
поднялся, `update.sh` обязан вернуть прежний бинарь, а не оставить сервер лежать.

**Как это сделано.** Перед заменой служба останавливается, база копируется в `/var/lib/hysteria-ward/backups/`,
прежний бинарь — рядом с новым. После запуска скрипт ждёт устойчивого `active` и совпадения версии; при отказе
возвращает бинарь и копию базы, затем поднимает прежнюю версию. `--repair` не меняет версию, а приводит в
порядок каталоги, права, временный режим сертификата и недостающие настройки: их дополняет и записывает
`hysteria-ward config --repair`, не трогая домен, пароль и пользователей. `--status` работает без root и не
открывает базу на запись.

**Рассмотренные варианты.** (1) Обновление только вручную, как решал ADR-0008 — отклонено по причине (2).
(2) Демон сам проверяет обновления и обновляется изнутри — отклонено: это даёт сетевому процессу право
перезаписывать собственный исполняемый файл, а при ошибке — не оставляет внешней стороны, способной откатить.
Скрипт вынесен наружу именно поэтому.
