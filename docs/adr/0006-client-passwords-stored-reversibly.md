# Пароли клиентов хранятся обратимо, без хеширования

**Статус:** принято

Пароли клиентов Hysteria хранятся в базе **в открытом виде**, защищённые правами файловой системы (0600) и
HTTPS-интерфейсом.

Причина: серверу для проверки клиента достаточно хеша, но менеджер сам генерирует клиентам пароли и обязан уметь
выдать их повторно — сгенерировать QR/URI можно только из настоящего пароля. Хеш дал бы ложное чувство защиты,
лишив базовой функции. ТЗ 4.3 и так требует защищать секреты правами ФС, а не хешированием.

**Последствия.** Компромисс устройства или чтение базы означает утечку всех паролей клиентов. Это осознанный
размен, и он же — главный источник риска в ADR-0004.
