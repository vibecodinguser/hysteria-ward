# Hysteria Ward

Панель управления сервером [Hysteria 2](https://v2.hysteria.network/) на VPS. Ставится одним скриптом на чистый
сервер, сама выпускает сертификат для домена, ведёт пользователей, выдаёт ключи `hysteria2://` и показывает
статистику.

## Статус

**Проект в стадии проектирования. Кода пока нет** — в репозитории лежат техническое задание, план реализации и
реестр принятых решений. Первый этап (фундамент) ещё не начат.

## Что планируется

- Установка на чистый VPS одной командой, с интерактивным конфигуратором: домен, сертификат, режим доступа,
  masquerade.
- Веб-панель по HTTPS на `panel.<домен>`, с обязательной авторизацией.
- По умолчанию панель доступна только через SSH-туннель; публичный доступ включается и выключается осознанно.
- Пользователи: создание, удаление, выпуск ключа `hysteria2://` и QR-кода.
- Статистика по каждому пользователю с историей за 1 ч / 3 ч / 24 ч / 7 суток, переживающая перезапуск панели.
- Masquerade: подставной ответ посторонним запросам — свой сайт или зеркало чужого.
- Обновление панели скриптом `update.sh`, не теряющее данные; повторный запуск безопасен.

Ядро Hysteria 2 работает **внутри процесса панели**, а не отдельной службой: это даёт прямой доступ к авторизации
клиентов и учёту трафика по каждому из них.

## Чего проект не делает

- Не управляет маршрутизацией, не создаёт сетевые интерфейсы, не правит файрвол. Панель обслуживает входящие
  подключения и в маршрутизацию чужого трафика не вмешивается.
- Не является клиентом Hysteria 2 — только сервером.
- Не управляет Hysteria 2 на роутерах. Для Keenetic — отдельный проект на базе
  [`awg-manager`](https://github.com/hoaxisr/awg-manager).
